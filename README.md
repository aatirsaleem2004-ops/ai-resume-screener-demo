# AI Resume Screener
### Web Dashboard & n8n Automation

A portfolio showcase of my AI-assisted resume screening project.

The project connects a custom web dashboard with an n8n workflow
to process PDF resumes and present structured candidate insights.

## Features

- PDF resume upload and OCR text extraction
- AI-generated strengths and skill-gap analysis
- Weighted screening score breakdown
- Candidate search, filters, and sorting
- Dashboard charts and CSV export
- Google Drive storage
- Google Sheets records
- Automated Gmail acknowledgments

## How It Works

1. Upload a PDF resume through the dashboard.
2. The n8n workflow extracts and processes the resume text.
3. AI generates a structured screening analysis.
4. Results are stored and displayed in the dashboard.
5. An email acknowledgment is sent.

## Technology Stack

HTML · CSS · JavaScript · Chart.js · n8n · OpenAI
Google Drive · Google Sheets · Gmail
